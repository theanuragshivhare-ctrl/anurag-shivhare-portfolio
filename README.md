# Anurag Shivhare — Developer Portfolio

A responsive React portfolio built with Vite. It introduces Anurag as a first-year BTech CSE student at CSJMU and showcases projects, current learning, and ways to connect.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it using `npm run preview`.

## Update profile and project links

Edit [`src/site-config.js`](./src/site-config.js) to change the GitHub profile, project repository URLs, or add a live URL for ISC Student Hub. The Metro Rush 2.0 live demo is already configured.

## Projects

- **Metro Rush 2.0** — browser-based three-lane endless runner, built with HTML, CSS, JavaScript, and Three.js.
- **ISC Student Hub** — ongoing student-focused project. Its current site files are preserved under [`public/isc-student-hub/`](./public/isc-student-hub/).

The Metro Rush game is preserved under [`public/metro-rush/`](./public/metro-rush/).

## Deploy

The project uses Vite's standard production build (`npm run build`) and can be deployed to Vercel with the Vite preset. No environment variables or secrets are required.
